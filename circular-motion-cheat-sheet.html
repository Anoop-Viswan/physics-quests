Circular Motion on One Page

One idea runs all of it: find the net force toward the center and set it equal to mv²/r. "Centripetal" is a job title, not a new force.

The 4-step recipe (every problem)

  1. FBD of real forces only (gravity, normal, tension, friction). No Fc arrow.
  2. Find the center. Choose + toward the center.
  3. ΣFin = mv²/r: forces pointing in are +, out are −.
  4. Solve in symbols, then check a limit (v→0? r→∞? does the sign make sense?).

Myths that cost points

  • ✗ "Centrifugal force": you feel inertia, not an outward force.
  • ✗ Constant speed → a = 0: the direction changes, so a = v²/r.
  • ✗ Released → flies outward: it goes along the tangent.
  • ✗ Tension points up at the top: a string always pulls toward the center.
  • ✗ Astronauts have no gravity: they're in free fall (about 0.9 g).
  • ✗ Heavier satellite → faster: m cancels in v = √(GM/r).

FRQ sentences that score

  • "Taking toward the center as positive, ΣF = mv²/r (Newton's 2nd law)."
  • "At the top, gravity points toward the center; at the bottom it points away, so…"
  • "Just barely / minimum speed → set FN (or T) = 0."
  • "The velocity changes direction, so the object accelerates toward the center."
  • Proportions: write the equation, then the ratio (F ∝ v² → 2² = 4).
