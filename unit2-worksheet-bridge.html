The Stack-and-Add Method

The key solves every multi-object problem the same way: one Fnet = ma per object, then add the equations. Internal tensions cancel like magic.

02

Example: hanging – table – hanging, with friction

  1. Pick the direction of motion first. The heavier side wins: 4 kg (40 N) beats 1 kg (10 N), so the system moves toward the 4 kg.
  2. Make + point along the motion for EVERY object: up for the 1 kg, right for the 5 kg, down for the 4 kg. The string "bends" the axis around the pulleys.
  3. Friction opposes the motion, so on the 5 kg it points left: Ffr = μFN = 0.1 × 50 = 5 N.
  4. Write Fnet = ma for each object, then ADD. T1 and T2 each appear once as + and once as −, so they cancel.
  5. Plug a back in to any single equation to get each tension.
1 kg:  T₁ − 10 = 1·a
5 kg:  T₂ − T₁ − 5 = 5·a
4 kg:  40 − T₂ = 4·a
+)     25 = 10·a → a = 2.5 m/s²
T₁ = 10 + 1(2.5) = 12.5 N
T₂ = 40 − 4(2.5) = 30 N

Shortcut check: a = (driving forces − resisting forces) ÷ (total mass) = (40 − 10 − 5) ÷ 10 = 2.5 m/s². Same answer, and only one line.

Same trick on a ramp

  • Along the ramp, gravity's pull is mg sinθ. Into the ramp it's mg cosθ, so FN = mg cosθ.
  • Compare the hanging weight with mg sinθ to find which way it moves. Friction then points the other way.
  • With friction: driving = hanging weight − mg sinθ − μmg cosθ.

Vertical version: helicopter + load

  • Whole system (heli + load): Flift − (M+m)g = (M+m)a → the lift force.
  • Load alone: T − mg = ma → the cable tension.
  • Moving down and speeding up? Then a points down, so the lift is less than the total weight.

Two Circular Problems
We Hadn't Covered

The Ferris wheel, and the puck tied through a hole to a hanging mass. Both are classic test favorites.

03

Ferris wheel vs. coaster loop: is the seat UNDER you or OVER you?

Ferris wheel, top: you sit ON the seat, so the seat pushes up (away from the center). Gravity points down (toward the center).
mg − N = mv²/r → N = m(g − ac)
You feel lighter. Bottom: N − mg = mv²/r → you feel heavier.
Coaster loop, top: you're upside down INSIDE the track, so the track pushes down (toward the center).
mg + N = mv²/r
Same position, opposite N! Always draw where the surface touches you before writing the equation.

"Turns 4 times a minute": the rpm pipeline

Puck on a table, string through a hole, hanging mass

  1. Hanging mass M is at rest (a = 0): T = Mg.
  2. The same string pulls the puck m toward the hole. That tension IS the centripetal force: T = mv²/r.
  3. Chain them: Mg = mv²/r → v = √(Mgr / m).

Intuition: spin the puck faster and it needs more pull than M's weight can give. M gets yanked up and the circle widens until things balance again.

Mg = T = mv²/r

FRQ move: "The tension needed is 1236 N, which is more than the 1000 N breaking strength, so the vine breaks." A number on each side plus a comparison word scores the point.

The 3-4-5 triangle

sin 37° = cos 53° = 0.6
cos 37° = sin 53° = 0.8
Problems using 37° or 53° are inviting this shortcut, so no calculator is needed.

Slanted force → N changes

Push down at θ: N = mg + F sinθ (more friction).
Pull up at θ: N = mg − F sinθ (less friction).
Only F cosθ moves the box forward.

Static friction = only what's needed

A block at rest on a 30° ramp: friction = mg sinθ (whatever balances it), not μsFN.

μsFN is the maximum, used only when it's "just about to slip".

Pushed at constant speed? a = 0, so friction = your push (70 N push → 70 N friction).

Ramp + kinematics: forces give a, then a gives motion

1. Fnet along the ramp → a (frictionless: a = g sinθ; sliding up with friction: a = −(g sinθ + μg cosθ)). 2. Pick a kinematics equation: Δx = v₀t + ½at² · v = v₀ + at · v² = v₀² + 2aΔx. 3. "How far up?" means v = 0 at the top. Frictionless round trip: the time up = the time down, so total = 2 × tup, and it comes back at the speed it started with.
